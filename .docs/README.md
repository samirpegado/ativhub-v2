# Documentação do Boilerplate de Contexto para IA

Bem-vindo à documentação do framework de padronização de contexto para agentes de IA em IDEs de desenvolvimento da Devfy.

## 📚 Índice

Leia os documentos nesta ordem para melhor compreensão:

1. **[O Problema](01-o-problema.md)**  
   Entenda por que esse boilerplate existe e qual problema ele resolve.

2. **[A Solução](02-a-solucao.md)**  
   Descubra como o boilerplate funciona e o que você ganha usando ele.

3. **[Como Usar](03-como-usar.md)**  
   Guia passo a passo para configurar e usar o boilerplate no seu projeto.

4. **[Exemplos Práticos](04-exemplos-praticos.md)**  
   Veja cenários reais de uso e prompts eficazes.

5. **[Perguntas Frequentes](05-perguntas-frequentes.md)**  
   Respostas para dúvidas comuns sobre configuração, uso e manutenção.

## 🚀 Início Rápido

Se você já conhece o conceito e quer começar agora:

```bash
# 1. Copie o boilerplate para seu projeto
cp -r caminho/para/boilerplate/* seu-projeto/

# 2. Rode o bootstrap
cd seu-projeto
python scripts/bootstrap_ai_context.py --write

# 3. Complete as informações de negócio
# Edite os arquivos em .ai/project/

# 4. Teste com seu agente de IA favorito
# Abra seu IDE e pergunte algo!
```

## 🎯 Para quem é isso?

- **Desenvolvedores** que usam assistentes de IA (Cursor, Copilot, Claude, etc)
- **Tech Leads** que querem padronizar o contexto da equipe
- **Novos membros** que precisam entender projetos rapidamente
- **Equipes** que querem documentação viva e sempre atualizada

## 💡 O que você vai aprender?

- Por que agentes de IA precisam de contexto
- Como estruturar documentação que IAs entendem
- Como manter o contexto atualizado com pouco esforço
- Como usar prompts eficazes com contexto padronizado

## 🛠️ Tecnologias suportadas

Este boilerplate foi otimizado para os projetos da Devfy:

- **Web:** Next.js + TypeScript + Supabase
- **Mobile:** Flutter

Mas pode ser adaptado para outras stacks.
